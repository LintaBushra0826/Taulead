# Taulead: Manufacturing Operations Management System

**Final-year project, BSc Software Engineering (Gold Medal), Riphah International University**

Taulead is a web application that helps manufacturers manage their operations in one place: raw material inventory, staff records and production processes, with real-time progress tracking and reports.

This repository contains the **React frontend** of the system.

## What it does

| Module | Features |
| --- | --- |
| User accounts | Secure registration and login, profile management, confirmation notifications |
| Raw materials | Custom measuring units, raw material entries, price logs, inventory reviews |
| Human resources | Employee records with role-specific details and termination logs |
| Process planning and execution | Processes and sub-processes, resource allocation, inventory tracking, real-time progress monitoring |
| Reporting | Logs and reports with charts and Gantt timelines to help optimise processes |

## Built with

- **React 18** with React Router
- **Ant Design**, Material UI and Bootstrap for the interface
- **Chart.js**, Ant Design Charts and Kendo Charts for dashboards and reporting
- **Gantt charts** for process timelines
- **Axios** for communication with the backend API

## Run it locally

```bash
npm install
npm start
```

Then open http://localhost:3000 in your browser.
